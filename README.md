# Meteorología Interactiva · ECMWF AIFS

Repositorio aislado para publicar mapas de **ECMWF AIFS Single v2** usados por Meteorología Interactiva.

- Datos: ECMWF Open Data.
- Horizonte: +360 h.
- Cadencia: 6 h.
- Dominios: España y Europa ampliada.
- Política: no inventar variables ni horas ausentes.
